## 🚀 Free 2-Minute Deployment Options

You do not need to buy a domain or paid hosting. You can host this website completely free using any of the following options:

### Option A: GitHub Pages (Recommended — 100% Free)
1. Push your repository to GitHub:
   ```bash
   git add website/
   git commit -m "Add Razorpay verified website landing page"
   git push origin main
   ```
2. On GitHub, go to your repository **Settings** &rarr; **Pages**.
3. Under **Build and deployment** &rarr; **Branch**, select `main` and folder `/website` (or root if dedicated repo).
4. Click **Save**. Your site will be live instantly at:
   `https://<your-username>.github.io/agristack-extension/website/`

### Option B: Vercel (1-Click Instant Deploy)
1. Go to [vercel.com](https://vercel.com) and log in with GitHub.
2. Click **Add New...** &rarr; **Project** &rarr; Import your repository.
3. In **Root Directory**, select `website` and click **Deploy**.
4. You will get a free HTTPS link (e.g. `https://agristack-helper.vercel.app`).

### Option C: Netlify (Drag and Drop in 30 Seconds)
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop the `website/` folder directly onto the page.
3. Your site is live immediately with a free `.netlify.app` domain.
